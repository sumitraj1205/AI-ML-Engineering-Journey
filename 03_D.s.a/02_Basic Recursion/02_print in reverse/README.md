# Print N to 1 Using Recursion

## Problem

Given a positive integer `N`, print all numbers from `N` to `1` using recursion.

## Approach

* If `N` becomes `0`, stop the recursion.
* Print `N`.
* Call the function with `N - 1`.
* The numbers are printed in descending order.

## Example

**Input:**

```text
5
```

**Output:**

```text
5
4
3
2
1
```

## Complexity

* **Time Complexity:** O(n)
* **Space Complexity:** O(n)
