# Recursion

This folder contains my practice and implementations of recursion problems in Python.

## Topics Covered

* Basics of Recursion
* Recursive Function Calls
* Base Case
* Recursive Case
* Recursion Tree
* Stack Overflow
* Tail Recursion
* Head Recursion
* Parameterized Recursion
* Functional Recursion
* Backtracking

## Problems

Some of the problems I have practiced:

* Print numbers using recursion
* Print numbers in reverse
* Sum of first N numbers
* Factorial of a number
* Fibonacci series
* Reverse an array
* Check if a string is palindrome
* Check if an array is sorted
* Binary search using recursion
* Power of a number
* Generate subsequences
* Generate permutations
* Basic backtracking problems

## Goal

The goal of this folder is to improve my understanding of recursion and learn how to approach problems using recursive thinking.
