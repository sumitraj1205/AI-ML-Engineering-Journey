# Linked List

This folder contains basic and important Linked List problems implemented using Python.

## Topics Covered

- Introduction to Linked List
- Inserting a Node in Linked List
- Deleting a Node in Linked List
- Find the Length of Linked List
- Search an Element in Linked List
- Design Linked List

## Key Concepts

- Node
- Head
- Next Pointer
- Traversal
- Insertion
- Deletion
- Searching
- Singly Linked List
- Custom Linked List Design

## Complexity

| Problem | Time Complexity | Space Complexity |
|---|---:|---:|
| Introduction | O(n) | O(n) |
| Insert Node | O(n) | O(1) |
| Delete Node | O(n) | O(1) |
| Find Length | O(n) | O(1) |
| Search Element | O(n) | O(1) |
| Design Linked List | O(n) | O(n) |
