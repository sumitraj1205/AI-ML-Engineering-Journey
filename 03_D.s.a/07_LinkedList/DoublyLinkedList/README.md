# Doubly Linked List

This folder contains basic and important Doubly Linked List problems implemented using Python.

## Key Concepts

- Node
- Head
- Previous Pointer
- Next Pointer
- Forward Traversal
- Backward Traversal
- Insertion
- Deletion
- Reversing a Linked List

## Complexity

| Problem | Time Complexity | Space Complexity |
|---|---:|---:|
| Introduction | O(n) | O(n) |
| Insert Node | O(n) | O(1) |
| Delete Node | O(n) | O(1) |
| Reverse DLL | O(n) | O(1) |
