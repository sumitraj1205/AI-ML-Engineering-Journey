# Recursion and Backtracking

In this section, I have solved various DSA problems using Python to improve my understanding of Recursion and Backtracking.

I have practised problems based on subsequences, subsets, combination sum, binary strings, parentheses generation, N-Queens and Rat in a Maze.

Through these problems, I learned how to use recursive calls, base conditions, take and not-take approaches, and backtracking to solve problems step by step.

**Language:** Python
