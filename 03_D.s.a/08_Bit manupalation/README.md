# Bit Manipulation

## About

In this section, I have learned the basics of Bit Manipulation and solved different problems using bitwise operators in Python.

Bit Manipulation is a technique of working directly with the binary representation of numbers. It helps solve certain problems efficiently using operations like AND, OR, XOR, NOT, left shift and right shift.

## Bitwise Operators

| Operator | Name | Description |
|---|---|---|
| `&` | AND | Sets a bit if both bits are 1 |
| `\|` | OR | Sets a bit if at least one bit is 1 |
| `^` | XOR | Sets a bit if both bits are different |
| `~` | NOT | Inverts the bits |
| `<<` | Left Shift | Shifts bits to the left |
| `>>` | Right Shift | Shifts bits to the right |
