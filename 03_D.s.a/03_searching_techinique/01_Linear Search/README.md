# Linear Search

## Problem

Given an array and a target element `X`, find the index of `X` using Linear Search.

If the element is not present, return `-1`.

## Approach

- Start from the first element.
- Compare each element with `X`.
- If a match is found, return its index.
- If the complete array is checked without finding `X`, return `-1`.

## Complexity

- Time Complexity: O(n)
- Space Complexity: O(1)
