# Searching

This folder contains important searching techniques and problems commonly used in Data Structures and Algorithms.

Searching is the process of finding a particular element or determining the position of an element in a data structure.

## Topics Covered

### Basic Searching
- Linear Search
- Binary Search 


### Linear Search

Linear Search checks every element one by one until the required element is found.

**Time Complexity:** O(n)  
**Space Complexity:** O(1)

### Binary Search

Binary Search works on a sorted array. It repeatedly divides the search space into two halves.

**Time Complexity:** O(log n)  
**Space Complexity:** O(1)


## Goal

The goal of this folder is to build a strong understanding of searching algorithms and their applications, especially Binary Search and its different variations.
