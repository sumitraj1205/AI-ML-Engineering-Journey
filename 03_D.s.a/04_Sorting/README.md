# Sorting

This folder contains important sorting algorithms implemented in Python.

Sorting is the process of arranging elements in a particular order, usually ascending or descending.

- Bubble Sort

### Advanced Sorting Algorithms

### Recursive Sorting

- Time and Space Complexity

## Sorting Algorithms

| Algorithm | Best Case | Average Case | Worst Case | Space |
|-----------|-----------|--------------|------------|-------|
| Selection Sort | O(n²) | O(n²) | O(n²) | O(1) |
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n)* |

\* Space complexity of Quick Sort depends on the recursion depth.

## Goal

The goal of this folder is to understand different sorting techniques, their implementations, and their time and space complexities.
