# Linear Regression

This folder contains my implementation and practice of Linear Regression.

I have implemented Linear Regression in two ways:

## 1. Basic Linear Regression

This section contains the implementation of Linear Regression using the available Machine Learning libraries.

It covers:

* Loading the dataset
* Splitting the data
* Training the Linear Regression model
* Making predictions
* Evaluating the model

## 2. Linear Regression From Scratch

This section contains my own implementation of Linear Regression without directly using the Linear Regression model from a Machine Learning library.

The purpose of implementing it from scratch is to understand what happens inside the model and how the parameters are learned.

## Concepts

* Linear relationship between features and target
* Training and prediction
* Model coefficients
* Intercept
* Mean Squared Error
* Model evaluation

## Libraries Used

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## Goal

The goal of this folder is to understand Linear Regression both from a practical point of view and from the implementation side by building it from scratch.
