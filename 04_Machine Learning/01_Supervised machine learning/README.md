# Supervised Machine Learning

This folder contains my learning and implementation of Supervised Machine Learning algorithms.

In Supervised Learning, the model learns from a dataset where the input features and the target/output are already known.

## Topics Covered

### Regression

* Linear Regression
* Multiple Linear Regression
* Polynomial Regression
* Ridge Regression
* Lasso Regression

### Classification

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Decision Tree
* Random Forest
* Support Vector Machine (SVM)
* Naive Bayes

## Basic Workflow

```text
Load Dataset
     ↓
Understand Data
     ↓
Data Cleaning
     ↓
Exploratory Data Analysis
     ↓
Data Preprocessing
     ↓
Train-Test Split
     ↓
Feature Scaling / Encoding
     ↓
Model Training
     ↓
Prediction
     ↓
Model Evaluation
     ↓
Model Improvement
```

## Model Evaluation

### Regression Metrics

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* R² Score

### Classification Metrics

* Accuracy
* Precision
* Recall
* F1 Score
* Confusion Matrix
* ROC-AUC

## Goal

The goal of this folder is to understand how different supervised learning algorithms work and to implement them on different datasets.

I will also compare different models and experiment with preprocessing, feature engineering and hyperparameter tuning as I continue learning Machine Learning.
