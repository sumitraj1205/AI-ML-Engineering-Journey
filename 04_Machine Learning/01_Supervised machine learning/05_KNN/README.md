# K-Nearest Neighbors (KNN) From Scratch

Implemented the **K-Nearest Neighbors (KNN)** algorithm from scratch using Python and NumPy.

## Topics Covered

* KNN Classification
* KNN Regression
* Euclidean Distance
* Finding K Nearest Neighbors
* Majority Voting
* Feature Scaling
* Choosing the value of K

## Implementation

The implementation includes:

* `fit()` method to store training data
* `predict()` method to make predictions
* Euclidean distance calculation
* Finding the K nearest data points
* Majority voting for classification
* Mean of neighbors for regression

## Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

> KNN algorithm is implemented from scratch without using Scikit-learn's KNN model.

## Learning

Through this implementation, I understood how KNN works internally and how distance between data points is used to make predictions.
