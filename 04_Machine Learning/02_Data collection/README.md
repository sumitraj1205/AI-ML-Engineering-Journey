# Data Collection

This folder contains my practice and learning related to **Data Collection** using Python.

I have explored different ways of collecting data from the internet, mainly:

* API
* Web Scraping

## Topics Covered

### 1. API Data Collection

Getting data from APIs using Python.

Topics include:

* Sending API requests
* Working with JSON responses
* Extracting required data
* Saving API data

### 2. Web Scraping

Collecting data from websites using Python.

Topics include:

* Sending requests to websites
* Working with HTML
* Extracting required information
* Saving scraped data

## Libraries Used

* `requests`
* `BeautifulSoup`
* `pandas`
* `json`
